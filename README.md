# OopsAllBlinkArrows (A Combination Towerfall Mod to FortRise V5+ Mod Port)
<img width="1189" height="600" alt="Screenshot 2026-09-02 174533" src="https://github.com/user-attachments/assets/175a5264-2d7d-4d08-a489-afded5844c28" />
A combination of [CoolModder's "Oops, All Arrows"](https://github.com/CoolModder/Towerfall-Redemption/releases/tag/v5.5.0-Arrows) and [KonspiracieTheorie's "Blink Arrows"]("https://github.com/KonspiracieTheorie/Blink-Arrows/releases/tag/2.1.0") Mods into one and ported to FortRise v5+.

## Who Made This

[CoolModder](https://github.com/CoolModder) made Oops, All Arrows and [KonsipiracieThorie](https://github.com/KonspiracieTheorie) mad Blink Arrows, I just ported them to the latest version of FortRise real quick with assistance from Claude. This will be taken down when there is a better, reliable way to play these mods on the newest FortRise version.

## Downloading and Running

1. Get the latest build from the [Releases page](../../releases) (newest version on top).
2. Unzip it anywhere on your PC.
3. Place the new folder into your [Fortrise](https://github.com/FortRise/FortRise) Mods folder.
4. Have fun!

## Note On AI Usage

This port was made with assistance from and uses some written code by Claude. AI should never be used in place of creativity, but for the sake of porting it can be a valuable tool.

Thank you.
